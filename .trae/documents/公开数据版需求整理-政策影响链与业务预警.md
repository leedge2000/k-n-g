# 粮油产业知识图谱需求整理：五层架构

> 文档性质：需求整理稿，不含实施方案与代码改动。
> 参照来源：《粮油产业知识图谱（含政策分析+供需预测+风险预警）完整架构》。
> 架构主线：**本体 Schema 层 → 实例事实层 → 时序事件层 → 政策语义层 → 智能推理预测预警层**。
> 整理日期：2026-11-15
> 数据前提：以互联网公开资料为主；企业内部类数据（产线、批次、库存、产能等）能力保留，数据需外部接入，缺数据时标注“无数据”，不得用公开数据反推。

## 二、第一层：本体 Schema 层

### 2.1 需求

1. 保留现有本体体系，不推翻、不重建。
2. 新增**政策本体大类**，与原有体系兼容：原有商品、主体、设施、工序、批次、市场、预测、预警；新增政策文件、政策条款、政策主体、政策时效、政策力度、适用对象。
3. 新增**企业生产域概念**：产线、工序、设备、工艺参数、批次、库存、产能，作为 B 档对象类型先建定义、后接数据。
4. 新增政策关系类型（见 5.2）。
5. 所有新增对象类型必须进入本体映射，不允许只在代码里定义而映射表缺失。
6. **全量抽取四套参考本体**（FoodOn / AGROVOC / DFC / KGAP），建立完整的底层本体镜像层；本地业务类型只做锚点映射，不复制外部全量层级。

### 2.2 输出

对象类型清单、关系类型清单、维度与范围定义、映射表条目、外部本体镜像表与抽取批次记录。每一项需可追溯到原架构的对应概念。

### 2.3 外部词表与标准（FoodOn / AGROVOC / DFC / KGAP）

**定位**：四套本体是底层本体模型的完整来源，**全量抽取**进系统，分两层承载：

- **参考本体镜像层**：四套本体的全部概念 / 类、层级、多语标签、定义、属性与关系，按原结构完整落库，只读、可溯源、按版本快照。
- **本地业务本体层**：现有对象类型与首期新增的政策域、生产域类型，是业务数据、推理与对外接口的唯一入口。

业务运行只认本地层与映射表；镜像层不直接参与业务判定，但为检索、术语扩展、同义词归一与对外交换提供完整底座。镜像层按整包抽取，不按场景挑条。

**抽取与转换规则**

1. **全量抽取**：按官方发布包整包抽取，不做人工剪裁；本地暂无业务场景的概念也保留，避免后续补抽造成断链。
2. **结构保真**：具名类、概念、层级、属性、定义、同义词、关系按原结构落库；外部 URI 是镜像身份，不改写、不重命名、不合并；匿名类表达式不冒充具名概念。
3. **分层存放**：外部本体只进镜像层，不直接成为业务对象类型；业务读写只落在本地业务本体层与映射表。
4. **标签策略**：标签与定义只保留显式中文和英文；`en-US`、`zh-Hans` 等归一到 `en / zh`，其他语种不入库。无 `xml:lang` 的字面量不猜测为英文，排除并记录 `label-language` 或 `definition-language` 留痕。
5. **锚点映射**：本地业务类型只与镜像层的少量锚点概念建立映射，不复制全量层级；一个外部概念最多挂一个本地类型，一个本地类型可对应多个外部概念。候选、已建、已复核必须分开，模糊匹配不得自动标为“已复核”。
6. **抽取留痕**：词表版本、发布包哈希、抽取时间、抽取条数、失败条数与失败清单必须记录，可按批次重放。复杂或缺失的 `domain / range` 不得为通过校验而丢属性，必须留空并留痕。
7. **版本策略**：整包版本替换，新旧快照并存；失效概念标记停用，不物理删除，历史引用可回溯。
8. **运行时形态**：抽取后统一转成本地关系表，运行时不解析 OWL / RDF；仅在对外交换时导出只读快照，不得回灌。
9. **许可与署名**：AGROVOC / FoodOn 为 CC BY 4.0；DFC 为 AGPL-3.0；KGAP 为 CC BY-NC 4.0，Almes Core / APTO 为 GPL-3.0。界面、导出物与接口说明中不得删除来源声明与署名。

**口径已定**：以本系统本地业务本体为准，`grain-oil-kg` 建模交付物只作参考输入；四套外部本体作为完整镜像层引入，但不改变本地对象类型定义。四套快照是否可发布以 V-01～V-11 实测为准，未达标不得强行发布。

### 2.4 底层本体模型：镜像表与映射关系

#### 2.4.4 约束

1. 一条外部概念在同一词表内只能有一条有效映射，重复须合并或标记停用。

| 要素 | 要求 |
| --- | --- |
| 区间形式 | 对目标变量的相对变动幅度，如“价格 +2%~+6%”，不给单一系数 |

| 必须标注 | 依据类型、引用条款、数据期间、置信等级（高 / 中 / 低） |
| 定性映射 | 区间中点 ≥5% 记为“强”，1%~5% 为“中”，<1% 为“弱”，仅作标签，不替代区间 |

| 配额 | 进口量 −10%~−30% | 配额量 / 进口量 |
| 准入 | 产量 −1%~−5% | 受影响产能占比 |
| 信贷 | 成本 −0.5%~−2% | 利率变动 / 资金成本 |
| 价格干预 | 价格 0%~限价上限 | 直接锁定价格区间 |

| 质量标准 | 成本 +1%~+4% | 达标改造成本 |

| 正式库隔离 | 联动验证在临时副本执行，正式库 `OpsAlert` 未被写入 |

### 6.5 可解释性

每条推理与预警输出都要给出：用了哪条政策条款、哪段原文、哪个时间点的哪条数据。无法给出依据的结论一律不输出。

### 6.6 政策影响链交付与预测/预警暂缓裁定（2026-11-16）

**交付范围：仅 6.1 第四行（方向变量）与 5.7 两个查询。**

| 项 | 实测 |
| --- | --- |
| 查询一 | `GET /api/policies/impacts?commodityId=&regionId=&asOf=`：返回政策 × 品种 × 地区 × 时点的现行有效影响链；方向只取 `POSITIVE→正向`、`NEGATIVE→负向`，其余与缺证据一律 `依据不足` |

## 八、验收口径

1. **五层贯通**：任取一条预警，可沿“预警 → 政策条款 → 实例事实 → 时序事件”逐层回溯到底。
2. **可复核**：随机抽取 10 条政策影响结论，人工核对原文段落，全部可对应。
3. **可回链**：任意预警可回溯到指标数据与原文证据。
4. **可离线**：断网环境下仍可查看已有政策原文与影响链结论。
5. **分档一致**：A 档结论可回指公开原文；B 档能力在无数据时输出“无数据”，不出现编造的企业内部数值。
