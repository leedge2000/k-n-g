DOCUMENT INGESTION

文档上传抽取

上传 Excel、Word、PDF、TXT、Markdown 或 CSV 原始文档，登记为来源文档并切分为可回溯段落，再据此派生知识。

① 登记来源上传原始文档，记录标题、发文机构与分类，系统计算校验和去重。
② 段落切分按标题层级与篇幅切分正文段落，供知识条目精确定位。
③ 派生知识Excel 自动识别表头抽取四类知识；其他文档进入录入页手工登记并绑定段落。
文档段落生成后可用于政策法规、指标数据、年鉴记录、农业情报与知识关系的来源回溯。
